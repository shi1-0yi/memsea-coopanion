# cortico-world-memsea

给 Coopanion 里的 bot 加一个**只读**的检索工具 `memsea_recall`。

上下文被清掉之后，她还能从记忆海的原始数据里把旧事捞回来——因为这个扩展读的是磁盘上的日志与笔记，不读她的上下文，也不写任何东西。

## 装

1. 把整个文件夹放到一个不会被挪走的位置（扩展按路径安装，装完再挪会失效）
2. Coopanion → 扩展页 → 安装 → **从本地目录**，选中这个文件夹
3. 在 World 总览里找到「记忆海」，**启用**
4. **重启应用**

不需要密钥、不需要配置、不需要常驻服务。

## 环境变量（在启动 Coopanion 的环境里设）

| 变量 | 作用 |
|---|---|
| `COOPANION_BOT_DIR` | 部署目录；不设就用宿主的 `botDir` |
| `COOPANION_OWNER_QQ` | 对方的 QQ，用来在结果里标"哥哥" |
| `COOPANION_SELF_QQ` | bot 自己的 QQ，用来标"她" |

不设也能用：识别说话人的主要依据是正文里的「你:」「哥哥:」这类前缀。

## 她会怎么用

```
memsea_recall({ query: "白名单", k: 8, days: 30 })
```

返回带时间和说话人的原文列表，最相关的在前：

```
记忆海里找到 2 条（查询「白名单」，范围 30 天，扫了 5271 条）：
1. [2026-10-26 20:13 · 事实库 · 哥哥] 这不对吧，我是不是忘整白名单了？
2. [2026-10-26 20:13 · 事实库 · 她] 我这边没被拦，照样发得出去……
```

- 用**关键词**，不要整句问话
- 带日期查更准：`10-30 看了什么视频`
- 查不到会说没找到，不会拿最近的话凑数

## 数据从哪来（只读）

`data/runs/*/events.jsonl`（气泡台词、QQ 收发、打字、语音转写）、`data/fact-store.json`、`workspace/diary/*.txt`，以及按天压缩的 B 站观看记录。

同一条话在多处出现的，按文本去重。

## 边界

- 检索是字面相似（中文 bigram + 关键词 + 近义词表），不是语义
- 只读：不写记忆、不改文件
- 扫盘一次约 5000 条、几十毫秒；日志到十万条要加索引
